# RainLoop Webmail 2.x documentation

This is an independently maintained fork of the archived
[RainLoop/rainloop-webmail](https://github.com/RainLoop/rainloop-webmail) project.
The maintainer actively uses RainLoop and is updating it for continued use.
Changes are maintained here and are not intended for merge-back into archived upstream.
The application name is retained; the separate maintained release line starts at 2.0.0.

- [Summary of today's 1.x → 2.x changes](MIGRATION-1.x-TO-2.x.md).
- [Upgrade from archived 1.x](UPGRADING.md): backups, deployment, breaking changes and rollback.
- [Development and security checks](DEVELOPMENT.md): frontend build, PHP lint and security scans.
- [License and third-party notices](../THIRD_PARTY_NOTICES.txt).
- [OpenBSD httpd example](../build/openbsd/httpd.conf).

The repository contains work toward 2.0.0. A version number or generated build
artifact does not by itself mean a public, production-ready release has been published.
